## Sobre o projeto

O **ATELIER Arquitetura & Interiores** é um projeto conceitual desenvolvido para portfólio, com foco em apresentação profissional, experiência do usuário e design responsivo.

**Segmento:** Arquitetura, interiores e identidade visual.

## Tecnologias utilizadas

- HTML5 — Estrutura semântica
- CSS3 — Design e responsividade
- JavaScript — Interatividade

## Objetivos

- Desenvolver uma interface moderna e profissional
- Aplicar conceitos de design responsivo
- Criar uma navegação intuitiva
- Explorar soluções visuais para o segmento
